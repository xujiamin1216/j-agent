# Phase 6: 可观测性

## 目标

让 Agent 的行为可调试、可追溯。

## 任务

| 任务 | 交付物 |
|------|--------|
| 追踪系统 | `observability/tracer.py`: LLM 调用/工具调用的结构化日志 |
| 调试模式 | `--debug` 实时显示完整请求/响应 |
| 执行轨迹 | `--trace` 输出到文件供事后分析 |
| 成本追踪 | 按 model 价格计算费用，会话结束输出总花费 |
